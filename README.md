# FINPROSE Workspace

Repositori Git berada di subdirektori **`FINPROSE/`**.

## YDA LAW OFFICE & Partners

Platform konsultasi hukum digital dengan asisten AI **Rusdi**, booking advokat, pembayaran manual, chat/meeting, dan document vault.

## Quick Start

```bash
cd FINPROSE
npm install
cp .env.example .env
npm run dev:all
```

| Service | URL |
|---------|-----|
| Frontend | http://localhost:3000 |
| API lokal | http://localhost:5000/api/health |
